# مجموعه صفحات آموزشی پردازش آماری الگو

شامل ۱۰ صفحه HTML و یک فهرست (`index.html`). برای شروع `index.html` را در مرورگر باز کنید. MathJax و فونت Vazirmatn از CDN بارگذاری می‌شوند؛ برای نمایش کامل فرمول‌ها و فونت به اینترنت نیاز است. تم روشن/تاریک، Presentation Mode، تب‌ها، تمرین‌های پاسخ‌دار و نمودارهای تعاملی در صفحات گنجانده شده‌اند.
